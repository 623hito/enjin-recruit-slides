# Enjin 採用説明会スライド (Web版)

株式会社Enjinの新卒/中途採用説明会で使用する22枚構成のWebスライドデッキ。

## 主な機能

- **16:9 固定キャンバス** をビューポートに自動フィット（あらゆる画面サイズで崩れない）
- **PowerPoint風サイドバー** — スライド一覧 + 本番に含めるかの切替
- **プレゼンモード** — フルスクリーン対応 + 矢印/Space/クリックで進行
- **22枚のエントランスアニメーション** — スクロールイン時にアクセント発動
- **URLハッシュ対応** — `#slide-5` で直接遷移
- **印刷/PDF出力** — 1スライド1ページの@page CSS対応
- **AI/デジタル風UI** — シアン×Enjin赤のハイブリッドアクセント
- **動画埋め込み** — `assets/` のmp4 or 賢者.TVの iframe を自動再生

## 使い方

ローカル起動：

```bash
python3 -m http.server 5180
# → http://localhost:5180
```

## 画像・動画の差し替え

`assets/README.md` 参照。指定ファイル名でドロップするだけで反映されます。

## キーボード

| キー | 動作 |
|---|---|
| `↓` / `→` / `Space` | 次へ |
| `↑` / `←` | 戻る |
| `Home` / `End` | 最初/最後 |
| `F` | フルスクリーン |
| `P` | プレゼンモード切替 |
| `Esc` | プレゼン終了 |
